# Changelog

Notable changes to Cobalt2 Themes are recorded here.

## 0.1.1 - 2026-10-10

### Added

- Add examples to the CLI and shell installer help.
- Support `-h` and `--help` in the npm CLI.

### Changed

- Align target listings in the npm CLI and shell installer.

## 0.1.0 - 2026-10-10

### Added

- Release Cobalt2 themes for 14 coding agent, terminal, and developer tool targets.
- Add npm/npx installation for Windows, macOS, and Linux.
- Add a POSIX shell installer for macOS and Linux.
- Add theme validation and cross-platform GitHub Actions checks.
